Approve asks for the account's passkey when the "Passkey for approvals" setting calls for it. This covers signing a message or typed data, granting a Nostr signer, delegating access to an app, signing an app's sign-in, approving a native app, allowing an app's TinyCloud signing and sharing TinyCloud key management. Settings shows the "Passkey for approvals" card again.

Details: TC-3442
