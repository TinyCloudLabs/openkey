Approval links now show where the request came from as "From a link" (or "From a link that names <host>"), with a note that OpenKey can't confirm who sent it, and say where the approval will be delivered: the TinyCloud MCP service, or an app on this device. Device sign-ins show "A device sign-in is asking" with the code to compare with the terminal, and approval requests without their own details show "An approval link is asking", instead of a fixed app name.
