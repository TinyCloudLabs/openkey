The approval screen for a sign-in is headed "Sign in to {app}" with the app named after "Requested by". A recap that hosts a space and a requester OpenKey cannot name keep the heading "Authorize capabilities". The Manifest ID tag reads "from the app's request; the manifest doesn't name one" when the matched manifest names no id, and "caller-supplied, unverified" is kept for an id with no matched manifest.

Details: TC-3921
