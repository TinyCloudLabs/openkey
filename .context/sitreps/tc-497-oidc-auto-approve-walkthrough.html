Trusted OIDC
auto-approval.

Thesis: a trusted confidential CoordinationOS client can complete the real Better Auth authorization flow directly to its exact callback, while every ordinary client remains consent-gated by default.

01

Public behavior

Trusted path

The admin API stores autoApprove: true as Better Auth's per-client skipConsent. The real /oauth2/authorize handler returns the user to the registered CoordinationOS callback with code and state.

Proven

Normal path

A second confidential web client with autoApprove: false receives a 302 to /oauth/consent, without a code and without a consent row.

Proven

Safety boundary

Only the ADMIN_API_KEY control plane can set the property. Non-web/public clients cannot enable it; the persisted schema default stays false for ordinary and dynamic registrations.
